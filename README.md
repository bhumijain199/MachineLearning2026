# Machine Learning 2026

## Project Overview

This repository contains laboratory work for the Machine Learning course.

The semester-long dataset used is the Olist Brazilian E-Commerce Public Dataset.

## Objectives

- Understand relational datasets
- Perform Exploratory Data Analysis (EDA)
- Analyze data quality
- Build a strong foundation for Machine Learning

## Project Structure

- data/raw/ - Original dataset files
- data/processed/ - Processed datasets
- notebooks/ - Jupyter notebooks
- reports/ - Reports and documentation
- figures/ - Generated plots
- src/ - Python scripts
- models/ - Machine Learning models

## Lab 1

Lab 1 focuses on:

- Loading the dataset
- Understanding relationships
- Data quality analysis
- Missing value analysis
- Initial business understanding
